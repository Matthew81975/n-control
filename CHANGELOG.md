# Changelog

## 0.2.0 - 2026-10-06

- Add weighted finite state spaces with normalized probability distributions and entropy.
- Add value/pointer states through the same state-space abstraction.
- Add reversible constraint pruning and explicit manual/weighted collapse.
- Add binary compatibility propagation across named N-Control dimensions.
- Add minimum-entropy and full-collapse policies suitable for generalized Wave Function Collapse.


## 0.1.1 - 2026-10-01

- Add optional Tk `NDimensionalKnob` widget.
- Add `auto_scan_enabled` boolean so apps can disable Auto Scan while preserving it as a reusable control capability.


## 0.1.0 - 2026-10-01

- Extract `ParameterAxis` and `SerpentineTraversal` from Genesis Forge tooling.
- Preserve bijective, reversible, neighbor-preserving N-D serpentine traversal.
- Add `NamedParameter` and `NamedParameterSpace` for semantic parameter dictionaries.
- Add packaging metadata, tests, documentation, and MIT license.
